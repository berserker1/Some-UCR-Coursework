# How to 0wn the Internet in Your Spare Time

## Problem Statement

The paper examines how self-replicating worms can rapidly compromise a significant portion of the internet within minutes.

## Pros

The paper thoroughly categorizes worms based on their scanning strategies (random scanning, hit-list scanning, permutation scanning. The research highlights the need for proactive defenses, inspiring later security advancements. Authors analyze actual worm outbreaks (e.g., Code Red, Slammer).

## Cons

While it discusses containment methods, it lacks practical implementation details. The model assumes that security teams react slower than the worm spreads, leading to widespread compromise. The study also assumes that systems are not patched or defended against zero-day exploits when worms emerge.



# EternalBlue – Everything There Is To Know: A Deep Analysis

## Problem Statement

EternalBlue is a cyberattack exploit developed by the U.S. National Security Agency (NSA) and later leaked by the hacker group known as the Shadow Brokers in April 2017. The exploit takes advantage of a vulnerability in the Microsoft Server Message Block (SMB) protocol (CVE-2017-0144). This vulnerability allows remote code execution (RCE) on unpatched Windows machines, enabling an attacker to gain control of a system without authentication.

## Pros

EternalBlue is widely seen as a cybersecurity threat. The exploit allows attackers to execute code remotely with minimal effort, making it an efficient attack. It also enables self-propagating malware, allowing rapid spread without requiring user. Once exploited, attackers can install backdoors, deploy additional malware, or take complete control over a system basically gaining persistence.

## Cons

One underlying assumption of the paper is that the authors think many systems were still using the outdated SMBv1 protocol, which lacked proper security mechanisms. Many affected organizations did not implement proper network segmentation, allowing rapid propagation of malware using EternalBlue. One important highlight is that the author needed to update this article as many developments regarding eternal blue have happened after 2017.
